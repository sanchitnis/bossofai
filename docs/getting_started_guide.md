# COLLABORATOR GETTING STARTED GUIDE: PROJECT PRODIGY

> **Welcome to Project PRODIGY!** Project PRODIGY operates on a two-tier collaborator structure:
> 1. **Core Meta-Venture Contributors (Project 0)**: Building, resourcing, deploying, and scaling PRODIGY itself in this GitHub repository.
> 2. **Community Users & Secondary Contributors**: Creating downstream project probes, learning via the Srujana Pathway, building external project repos, and sharing artifacts for community use.

---

## 🏗️ PART 1: For Core Meta-Venture Contributors (Project 0)

#### Goal: Develop, maintain, resource, deploy, and scale PRODIGY as an AI-augmented Meta-Venture Studio.

If you are a Core Contributor (AI Venture Orchestrator, Core Developer, Systems Architect, or AI Subagent) working directly on **Project 0**:

1. **Step 1 — Review Task Board**: Check active tasks on the [Project 0 Task Board](../planning/task_board.md) (`Backlog`, `In Progress`, `Under Review`, `Done`).
2. **Step 2 — Follow System Guidelines**: Adhere strictly to [AGENTS.md](../AGENTS.md) for relative markdown linking, file organization (`docs/`, `strategy/`, `planning/`, `wiki/`, `notebooks/`, `logs/`, `data/`), and local git commit protocols.
3. **Step 3 — Execute & Log**:
   - Log multi-AI suggestions or architectural proposals in [`logs/agent_suggestions.md`](../logs/agent_suggestions.md).
   - Log daily progress, blockers, and next steps in [`planning/standups_and_contributions.md`](../planning/standups_and_contributions.md).

---

## 🌐 PART 2: For Community Users & Downstream Venture Builders (Projects 1..N)

#### Goal: Hatch high-impact social/technical ventures, master the 4 C skills, build portfolios, and share digital public goods.

If you are a Community User, Student, Faculty Lead, Startup Founder, Mentor, or Support Partner:

### 🎓 1. Students & Life-Long Learners
1. **Register**: Complete the [Official Google Form Registration](https://docs.google.com/forms/d/e/1FAIpQLSf6CkQQXXr3306tPjUFi6nODpdLXT-F6uyFrLpoEcK5iBAa5Q/viewform) managed by Dr. Sanjay Chitnis (`sanjay.chitnis@gmail.com`).
2. **Explore Projects & Probes**: Browse existing venture probes in the [Web Portal Showcase](https://bossofai.org#projects) or inspect [`data/projects.json`](../data/projects.json).
3. **Hatch or Join a Probe**:
   - Create your own downstream project repository on GitHub (or join an existing team).
   - Point your external repo URL back to PRODIGY's showcase registry by submitting an issue or pull request updating `data/projects.json`.
   - Learn via the [Obsidian Wiki](../wiki/index.md) and [AI Prompt Playbook](../notebooks/prompt_playbook.md).

### 👨‍🏫 2. Mentors & HEITL Jury Members
1. **Register**: Complete the [Google Form Registration](https://docs.google.com/forms/d/e/1FAIpQLSf6CkQQXXr3306tPjUFi6nODpdLXT-F6uyFrLpoEcK5iBAa5Q/viewform) selecting *Mentor / HEITL Expert*.
2. **Review & Guide**: Review student probe repositories and assign Solution Maturity Index (SMI 1–10) scores using the [AI Review Checklists in AGENTS.md](../AGENTS.md).
3. **Co-Create & Advisory**: Guide high-SMI Stage 3/4 ventures toward enterprise incubation, IP filings, or equity advisory roles.

### 🏛️ 3. Institutional Hubs (Universities, Colleges & R&D Labs)
1. **Register Hub**: Register your institution via the Google Form.
2. **Adopt Srujana Pathway**: Integrate the 4 Developmental Stages ([references/srujana-pathway.md](../references/srujana-pathway.md)) into capstone courses or student clubs.
3. **Track Rankings**: Compete on the live global [Leaderboard Showcase](https://bossofai.org#leaderboard).

### 🛠️ 4. Support Experts & Partners (IP Attorneys, Infra Providers, VCs)
1. **Register**: Complete registration as a *Support Expert / Partner*.
2. **Access Vetted Deal-Flow**: Review high-SMI Stage 3 & 4 ventures ready for patent filing, enterprise licensing, or seed funding.
