## ⚡ Resource Procurement Strategy (Cloud & AI Credits)

To power PRODIGY's pre-competitive compute pool and AI multi-agent R&D, we will target the following grant & credit programs:

| Provider | Program | Targeted Resources | Primary Use Case |
| :--- | :--- | :--- | :--- |
| **Google Cloud** | Google Cloud for Startups / AI Grants | \$25,000 – \$100,000 in GCP credits & Gemini API quota | AI agent hosting, model fine-tuning, compute pooling for student teams. |
| **OpenAI** | OpenAI Developer / Non-Profit Grants | API credits for GPT-4o & embeddings | Multi-agent orchestration, automated eval benchmarking, cross-validation. |
| **Amazon Web Services** | AWS Activate / Cloud for Social Impact | \$10,000 – \$25,000 AWS credits | Scalable infrastructure, database hosting, web service backend. |
| **Microsoft** | Microsoft for Startups Founders Hub | \$150,000 Azure credits + GitHub Enterprise | Azure OpenAI Service, GitHub Copilot workspace access for student leads. |
| **Anthropic** | Anthropic API Credits / Startup Program | Claude 3.5 Sonnet API access | Strategic review, complex reasoning, and multi-agent synthesis. |

## 🤝 Team & Ecosystem Acquisition ("Project 0")

The first operational project of PRODIGY is building its own leadership and mentor network:

- **Human Core Leads**: Strategic Lead, Technical/AI Director, Academic Ecosystem Director, Venture Studio Director.
- **Mentor Network (HEITL Jury)**: Senior engineers, researchers from MIT/Stanford/IITs, serial founders, and social sector leaders.
- **Institutional Hubs**: Partnering with forward-thinking universities and institutes to embed PRODIGY micro-challenges into undergraduate/graduate research pathways.
