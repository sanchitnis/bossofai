# Manifest - Presentation Creator

This manifest lists the directories, files, templates, inputs, outputs, and scripts under `tools/presentation-creator/`.

## Core Files & Scripts

- [convert.py](./convert.py): Main Python script that reads the markdown input and compiles it to single-page HTML slides.
- [template-default.html](./template-default.html): Baseline/reference HTML file displaying the intended premium aesthetic, styling, navigation, and interactive quiz component behaviors.
- [requirements.txt](./requirements.txt): List of Python libraries required for conversion.

## Documentation & Guidance

- [README.md](./README.md): Overview, file structure, and requirements.
- [QUICKSTART.md](./QUICKSTART.md): Step-by-step developer setup and local verification guide.
- [AGENTS.md](./AGENTS.md): Coding rules, parsing requirements, and directory constraints for AI agents.
- [input-template.md](./input-template.md): Hybrid markdown structure specification.
- [specification.md](./specification.md): Interactive Presentation Specification (IPS) Version 1.0 outlining the React, MDX, and H5P roadmap.
