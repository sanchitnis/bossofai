# Step 1: Setting Up

First, let's install the necessary Python libraries.

Run the following command in the terminal:
```bash
pip install pandas matplotlib
```

Once installed, we'll create a dummy dataset to work with.

Run this to create `data.csv`:
```bash
echo "Student,Score,Grade
Alice,85,A
Bob,72,B
Charlie,missing,F
Dave,91,A" > data.csv
```

Notice that Charlie's score is "missing". We'll fix that using AI in the next step.
