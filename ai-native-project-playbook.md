# AI-Native Project Playbook - Boss of AI (bossofai.org)

This playbook defines how collaborative projects in Boss of AI move from an initial spark into high-impact, deployed assets through human-in-the-loop AI pairing.

---

## 🔁 The AI-Native Project Loop for Creating Artifacts

All project files are numbered sequentially so that they appear in exact chronological creation and concept dependency order in all directory listings:

```text
projects/<project-slug>/
├── 0_context.md     # Standing Foundation: facts, institutional constraints, style
├── 1_intent.md      # Stage 1: Envision (problem, audience, done criteria)
├── 2_spec.md        # Stage 2: Scope (locked architecture, requirements, non-goals)
├── 3_draft.md       # Stage 3: Build (AI-native comprehensive first-pass draft)
├── 4_review.md      # Stage 4: Test (red-team critique, factual verification, human expert gate)
├── 5_final.md       # Stage 5: Deploy (polished, authoritative deliverable committed for impact)
└── 6_feedback.md    # Stage 6: Iterate (field outcomes, stakeholder impact, next cycle triggers)
```

### Stage 0: Standing Foundation (`0_context.md`)
- Standing project-specific facts, institutional background, standing constraints, and key decisions.
- Read cold before starting any work so agents and human collaborators share bedrock context.

### Stage 1: Envision (`1_intent.md`)
- Capture the raw pain point, opportunity, target stakeholders, and intended outcome.
- Serves as the durable seed before starting structural drafting.

### Stage 2: Scope (`2_spec.md`)
- Lock the document architecture, target audience, non-goals, evidence requirements, and tone.
- **The Spec Rule**: High-stakes deliverables (institutional roadmaps, curricula, venture frameworks) must have a locked `2_spec.md` approved by the human collaborator before drafting.

### Stage 3: Build (`3_draft.md`)
- AI agents generate comprehensive first-pass drafts, synthesis, diagrams, and citations.
- Human experts provide domain grounding, contextual nuance, and direction.

### Stage 4: Test (`4_review.md`)
- Red-team critique, factual verification, pedagogical soundness, and adversarial review.
- Identifies gaps, hallucinations, or ungrounded assumptions. Layer 2 gate requires human sign-off.

### Stage 5: Deploy (`5_final.md`)
- Polished, authoritative deliverable committed for institutional deployment, sharing with stakeholders, or execution.

### Stage 6: Iterate (`6_feedback.md`)
- Capture real-world outcomes, stakeholder reactions, and field performance to seed future project cycles.

## 👥 Division of Labor: AI Agents vs. Human Experts

| Dimension | AI Agent Responsibility | Human Expert Responsibility |
| :--- | :--- | :--- |
| **Pacing & Speed** | Instant first-pass drafting, multi-angle outlines, rapid formatting | Sets priorities, rhythm, deadlines, and project milestones |
| **Evidence & Synthesis**| Cross-referencing wiki sources, literature synthesis, citation tracking | Supplies institutional wisdom, tacit knowledge, and moral compass |
| **Review & Quality** | Structural consistency, grammatical polish, red-team fact checks | Final approval gate, political sensitivity, contextual judgment |
